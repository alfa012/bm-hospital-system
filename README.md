## How to enable GitHub Pages
1. Open this repo → **Settings** → **Pages**
2. Under **Source**: select **Deploy from a branch**
3. Branch: **main** · Folder: **/ (root)**
4. Click **Save**
5. Wait 1–2 minutes, then open: https://alfa012.github.io/bm-hospital-system/
